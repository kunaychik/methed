**ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ:**
**КРОССБРАУЗЕРНОСТЬ**
Сайт должен иметь адаптивную вёрстку и корректно отображаться на компьютере,
планшете и мобильном устройстве. Вся информация доступна и отображается для
пользователя.
Проект должен одинаково отображаться в браузерах Chrome, Firefox, Safari, Opera, Edge.
В планшетной/мобильной версии: меню представляет собой кнопку
Ваша задача сверстать, а не писать функционал
**ШАПКА САЙТА**
Логотип — располагается в левой части меню.
Использовать векторное изображение для
лучшего отображения.
Меню — при клике на пункт меню
осуществляется плавный переход к
соответствующему блоку.
Стрелка в первой секции является ссылкой, при
клике на которую страница плавно опускается к
следующей секции.

**ТЕХНОЛОГИЧЕСКИЕ ТРЕБОВАНИЯ:**
Чистая, адаптивная, семантическая вёрстка.
Стремитесь минимизировать в коде количество
тегов и вложенностей.
Максимально близкая вёрстка к макету, без
явных видимых отличий.
В каждом из браузеров должна открываться
абсолютно идентичная вёрстка в портретном и
альбомном режиме.
БЭМ-именование классов и структура проекта.
Стремитесь использовать минимальное количество
брейкпоинтов в вёрстке.
Избегайте дублирования кода, насколько это
возможно.
Все интерактивные элементы должны иметь эффекты:
hover, active, focus.
